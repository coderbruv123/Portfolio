Your orbs, but reactive

Your current background has three static blurred orbs drifting on infinite loops. This mock keeps that DNA and adds a spotlight that follows the cursor — the dominant "ambient background" pattern in 2026 portfolios.

Implementation is tiny: one mousemove listener, rAF-throttled, writing --mx/--my CSS variables onto a single div with a radial-gradient. No canvas, no WebGL, GPU-friendly.

GPU-safeOnly CSS vars change — no layout, no repaint storm
rAF throttledOne paint per frame max, regardless of mouse events
Touch fallbackVars default to 50%/30% — mobile keeps the old look
